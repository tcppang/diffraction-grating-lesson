# Diffraction Grating: self-learning lesson (HKDSE Physics)

Interactive lesson, simulation and practice for the diffraction grating and double slit.

Live site: https://tcppang.github.io/diffraction-grating-lesson/

Outcomes: calculate d from lines per mm; apply d sin θ = nλ; find the maximum order; find fringe positions with y = D tan θ.
Everything is in one file, `index.html`, with no build step.
